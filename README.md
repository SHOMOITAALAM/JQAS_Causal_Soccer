README: Code for "Framing Causal Questions in Sports Analytics: A Case Study of Crossing in Soccer"
This repository contains the R code supporting the analyses and figures presented in the manuscript:

Alam, S., Moodie, E. E. M., Wu, L. Y., and Swartz, T. B.
Framing causal questions in sports analytics: A case study of crossing in soccer.
Submitted to Journal of Quantitative Analysis in Sports.
